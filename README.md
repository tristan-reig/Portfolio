# Portfolio 3D

Portfolio personnel sous forme de scène 3D interactive : un bureau que l'on explore
directement dans le navigateur, plutôt qu'une page à faire défiler.

Projet en cours de développement.

## Inspiration

Inspiré par [henryheffernan.com](https://henryheffernan.com/)
([dépôt](https://github.com/henryjeff/portfolio-website)), avec une direction
artistique et une scène entièrement personnelles — plus réaliste, et dans un
registre bureau d'entreprise plutôt que chambre rétro.

## Stack

- **Vite** + **React** + **TypeScript**
- **Three.js** via [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Blender** pour la modélisation, l'assemblage et le baking de l'éclairage

## Démarrage

```bash
npm install
npm run dev
```
